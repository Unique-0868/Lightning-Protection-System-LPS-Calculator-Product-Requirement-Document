# Lightning-Protection-System-LPS-Calculator-Product-Requirement-Document
LPS a web application that helps create IEC 62305-compliant LPS designs for buildings of any size.  Using building geometry and system parameters, it calculates the required number of lightning arrestors, optimal roof placement, separation distances, protection radii, and design recommendations in accordance with international standards.
